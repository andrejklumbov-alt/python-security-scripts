# Custom Pentest & OSINT Automation Toolkit

Персональный комплекс автономных скриптов и модулей на языке Python, разработанный для автоматизации задач в области информационной безопасности, сетевого скрининга, криптографического анализа и обработки данных. 

Каждая утилита спроектирована как независимый инструмент для пассивного аудита ИТ-инфраструктуры и верификации конфигураций L7-уровня.

## Структура репозитория (Repository Architecture)

* **network_scanners/** — Асинхронные и многопоточные инструменты для пассивного сбора HTTP-заголовков, проверки ответов серверов и верификации защитных директив (`HttpOnly`, `X-Frame-Options`, `CSP`).
* **bruteforce_tools/** — Модули для тестирования устойчивости механизмов аутентификации веб-форм методом эмуляции POST-запросов (перебор параметров).
* **crypto_utils/** — Скрипты для проверки механизмов хэширования, валидации целостности данных и криптографической защиты паролей.
* **multithreading/** — Шаблоны и примеры оптимизации сетевых потоков для повышения производительности сокетов.
* **storage/** — Слой интеграции с СУБД (SQLite) для локального структурированного хранения результатов сканирования и логов киберразведки.
